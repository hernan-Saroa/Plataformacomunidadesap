## 🎯 DIFERENCIA CLAVE: CARPETA DIGITAL vs EXPEDIENTE ELECTRÓNICO

### 📁 **RF003 - CARPETA DIGITAL**
```
ROL: Herramienta de TRABAJO DIARIO
USUARIO: Profesional asignado al caso
PROPÓSITO: Gestión activa y creación de documentos

✅ Subir documentos nuevos
✅ Redactar autos (borradores)
✅ Cargar evidencias
✅ Gestionar notificaciones
✅ Trabajo en progreso
✅ Documentos en diferentes estados
```

### 📦 **RF005 - EXPEDIENTE ELECTRÓNICO**
```
ROL: ARCHIVO OFICIAL Y COMPLETO
USUARIO: Jefe OCID, Auditores, Entidades Externas
PROPÓSITO: Expediente oficial certificado

✅ Solo documentos FIRMADOS y FINALES
✅ Índice electrónico oficial (foliado)
✅ Trazabilidad y auditoría completa
✅ Exportación oficial (PDF certificado)
✅ Archivo histórico del proceso
✅ Cumplimiento normativo (Ley 594/2000)
```

## 🔗 INTEGRACIÓN ENTRE MÓDULOS

### **Flujo de un Documento (Ejemplo: Auto de Apertura)**

```
1. 📝 CREACIÓN (RF003 - Carpeta Digital)
   └─ Profesional Juan Carlos redacta "Auto de Apertura"
   └─ Documento estado: BORRADOR

2. 🔍 REVISIÓN (RF004 - Revisión y Aprobación)
   └─ Envía a Jefe OCID para revisión
   └─ Jefe revisa y devuelve con observaciones
   └─ Profesional corrige (Versión 2, Versión 3...)
   └─ Jefe aprueba versión final

3. ✍️ FIRMA (RF004 - Revisión y Aprobación)
   └─ Jefe OCID firma digitalmente
   └─ Documento estado: FIRMADO ✅

4. 📨 NOTIFICACIÓN (RF003 - Carpeta Digital)
   └─ Secretaría notifica al investigado
   └─ Documento estado: FIRMADO ✅ + NOTIFICADO ✅

5. 📦 ARCHIVO OFICIAL (RF005 - Expediente Electrónico)
   └─ Documento FINAL se integra automáticamente
   └─ Aparece en el índice electrónico con folio
   └─ Auditoría registra toda la trazabilidad
   └─ Disponible para exportación oficial
```

## 📊 CASOS DE USO DEL EXPEDIENTE ELECTRÓNICO

### **1. Auditoría Interna de la Procuraduría**
```
Auditor: "Necesito revisar el expediente completo del proceso P-120-2025"
→ Entra a RF005 - Expediente Electrónico
→ Busca "P-120-2025"
→ Ve todos los documentos FINALES y FIRMADOS
→ Revisa índice electrónico foliado
→ Verifica trazabilidad en auditoría
→ Exporta PDF oficial certificado
```

### **2. Solicitud de Ente de Control Externo**
```
Contraloría: "Solicito expediente completo de proceso contra Ana López"
→ Jefe OCID entra a RF005
→ Busca "Ana María López Hernández"
→ Selecciona proceso P-045-2024
→ Click "Exportar Expediente PDF"
→ Sistema genera PDF con:
   • Carátula oficial
   • Índice electrónico completo
   • Todos los documentos en orden cronológico
   • Metadatos de firma y notificación
   • Código QR de verificación
→ Entrega PDF oficial
```

### **3. Cierre de Proceso Disciplinario**
```
Profesional: "El proceso P-089-2024 se archivó por prescripción"
→ Se genera Auto de Archivo (RF003)
→ Jefe firma auto de archivo (RF004)
→ Expediente completo se cierra (RF005)
→ Estado cambia a "Archivado"
→ Expediente completo exportado a PDF
→ Se guarda en repositorio institucional
→ Auditoría completa queda registrada
```

### **4. Apelación o Recurso**
```
Investigado: "Apelo la decisión"
→ Caso sube a segunda instancia
→ Nueva autoridad necesita TODO el expediente
→ Entra a RF005
→ Busca proceso P-156-2025
→ Descarga expediente completo en PDF
→ Tiene acceso a:
   • Todos los autos firmados
   • Todas las evidencias
   • Todas las notificaciones
   • Historial completo de versiones
   • Auditoría de cada documento
```

## ✅ CONCLUSIÓN

El **Expediente Electrónico (RF005)** NO reemplaza la Carpeta Digital (RF003), sino que la COMPLEMENTA:

- **Carpeta Digital (RF003)** = Herramienta de TRABAJO
- **Expediente Electrónico (RF005)** = ARCHIVO OFICIAL

Ambos son necesarios, pero sirven propósitos diferentes en el flujo del proceso disciplinario. El Expediente Electrónico es la **memoria institucional certificada** de todo el proceso, garantizando transparencia, trazabilidad y cumplimiento normativo.
