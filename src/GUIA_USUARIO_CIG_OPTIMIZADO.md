## 📊 **MÓDULO 1: DASHBOARD KANBAN**

### **¿Qué es?**
El **centro de comando** donde ves todas las auditorías en curso.

### **¿Qué puedo hacer aquí?**
- ✅ Ver todas las auditorías organizadas por fase
- ✅ Arrastrar tarjetas entre columnas (Drag & Drop)
- ✅ Ver métricas ejecutivas
- ✅ Acceder rápidamente a cualquier auditoría
- ✅ Filtrar por territorial o búsqueda

### **Columnas del Kanban:**

```
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│📋 PLAN   │🔍 PLAN   │⚡ EJEC   │💬 COMU   │🔺 MEJOR  │✅ CIERRE │
│(4)       │(8)       │(15)      │(6)       │(5)       │(23)      │
├──────────┼──────────┼──────────┼──────────┼──────────┼──────────┤
│          │          │          │          │          │          │
│ [Card 1] │ [Card 1] │ [Card 1] │ [Card 1] │ [Card 1] │ [Card 1] │
│ [Card 2] │ [Card 2] │ [Card 2] │          │          │ [Card 2] │
│          │ [Card 3] │ [Card 3] │          │          │          │
│          │          │          │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
```

### **Anatomía de una Tarjeta:**

```
┌──────────────────────────────────────┐
│ 🏢 Gestión Financiera Bogotá        │
│ AUD-2025-002                         │
│ ──────────────────────────────────── │
│ 📅 15/Ene - 30/Mar | 👤 María García │
│ 🎯 Progreso: ████████░░ 80%         │
│ ⚠️ 3 Hallazgos | 📄 12 Evidencias   │
│ ──────────────────────────────────── │
│ [📋 Ver] [⚡ Ejecutar] [📊 Info]    │
│                                      │
│ 🔔 Vence en 5 días                  │
└──────────────────────────────────────┘
```

### **Colores de Alerta:**

🟢 **Verde:** En tiempo, progresando bien  
🟡 **Amarillo:** Por vencer en 5 días  
🔴 **Rojo:** Atrasada, requiere acción inmediata

## 📋 **MÓDULO 2: PLANIFICACIÓN**

### **¿Qué es?**
Donde **preparas** todas las auditorías del año.

### **4 Tabs (pasos secuenciales):**

```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│ 📋 PLAN     │  🌐 UNIVERSO│  📅 PROGRAMA│  ▶️ INICIO  │
│   ANUAL     │             │             │             │
│ ━━━━━━━━━━━ │             │             │             │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

### **Tab 1: Plan Anual (RF001)**

**¿Qué hago aquí?**
- Define **QUÉ** procesos vas a auditar durante el año
- Establece objetivos estratégicos
- Asigna recursos y presupuesto

**Indicador visual:**
```
💡 Define QUÉ procesos auditar durante el año
```

**Al terminar:**
```
[Ir a Universo →]
```

### **Tab 2: Universo de Auditorías (RF002)**

**¿Qué hago aquí?**
- Identifica **TODOS** los procesos auditables de la entidad
- Clasifica por áreas y territoriales
- Define prioridades

**Al terminar:**
```
[Ir a Programa →]
```

### **Tab 3: Programa Anual (RF003)**

**¿Qué hago aquí?**
- Programa **CUÁNDO** se ejecutará cada auditoría
- Define cronograma anual
- Asigna equipos auditores

**Al terminar:**
```
[Iniciar Auditoría →]
```

### **Tab 4: Inicio de Auditoría (RF004)**

**¿Qué hago aquí?**
- Formaliza el inicio de una nueva auditoría
- Wizard paso a paso:
  1. Información básica
  2. Alcance y objetivos
  3. Equipo auditor
  4. Cronograma inicial

## 🎯 **MÓDULO 3: PROCESO DE AUDITORÍA**

### **¿Qué es?**
Donde **ejecutas** las auditorías activas.

### **3 Tabs (flujo del proceso):**

```
┌─────────────┬─────────────┬─────────────┐
│ 🔍 PLAN     │  ⚡ EJECUC  │  💬 COMUNIC │
│   DETALLADA │             │             │
│ ━━━━━━━━━━━ │             │             │
└─────────────┴─────────────┴─────────────┘
```

### **Tab 1: Planeación Detallada (RF005)**

**¿Qué hago aquí?**
- Planea **CÓMO** ejecutar la auditoría
- Define alcance detallado
- Establece metodología
- Prepara listas de chequeo

**Indicador visual:**
```
💡 Planea CÓMO ejecutar la auditoría: alcance, metodología y recursos
```

### **Tab 2: Ejecución (RF006-008)**

**¿Qué hago aquí?**
- **Ejecuta** la auditoría en campo
- Recolecta evidencias
- Registra hallazgos
- Documenta observaciones

**Acciones clave:**
- 📎 Cargar evidencias
- ⚠️ Registrar hallazgos
- 📊 Ver avance
- 💾 Guardar progreso

### **Tab 3: Comunicación (RF009)**

**¿Qué hago aquí?**
- Comunica resultados a áreas auditadas
- Envía informes preliminares
- Recibe respuestas y descargos
- Consolida informe final

## 🔺 **MÓDULO 4: PLANES DE MEJORAMIENTO**

### **¿Qué es?**
Donde gestionas los **hallazgos** y sus correcciones.

### **2 Tabs:**

```
┌─────────────┬─────────────┐
│ ✍️ FORMUL   │  📈 SEGUIM  │
│   -ACIÓN    │   -IENTO    │
│ ━━━━━━━━━━━ │             │
└─────────────┴─────────────┘
```

### **Tab 1: Formulación (RF010)**

**¿Qué hago aquí?**
- Formula planes de mejoramiento basados en hallazgos
- Define acciones correctivas
- Asigna responsables
- Establece fechas de cumplimiento

### **Tab 2: Seguimiento (RF011)**

**¿Qué hago aquí?**
- Hace seguimiento al cumplimiento
- Revisa evidencias de mejora
- Actualiza estados
- Cierra hallazgos resueltos

**Semáforo de seguimiento:**
- 🟢 Al día
- 🟡 Por vencer
- 🔴 Vencido

- Organiza por categorías
- Controla versiones
- Descarga masiva

### **Tab 3: Notificaciones (RF014)**

**¿Qué hago aquí?**
- Gestiona alertas automáticas
- Configura recordatorios
- Ve historial de notificaciones
- Activa/desactiva alertas

## 🎓 **GUÍA DE USO: FLUJO COMPLETO**

### **Escenario: Ejecutar una auditoría de principio a fin**

#### **PASO 1: Preparación (Planificación)**

```
1. Ir a "📋 Planificación"
2. Click en tab "Plan Anual"
3. Definir qué auditar este año
4. Click [Ir a Universo →]
5. Definir procesos auditables
6. Click [Ir a Programa →]
7. Programar fechas de auditorías
8. Click [Iniciar Auditoría →]
9. Completar wizard de inicio
```

#### **PASO 2: Ejecución (Proceso de Auditoría)**

```
1. Ir a "🎯 Proceso de Auditoría"
2. Click en tab "Planeación"
3. Definir alcance detallado
4. Click [Ir a Ejecución →]
5. Recolectar evidencias
6. Registrar hallazgos
7. Click [Ir a Comunicación →]
8. Enviar informes a auditados
9. Recibir respuestas
```

#### **PASO 3: Mejoramiento (Planes de Mejoramiento)**

```
1. Ir a "🔺 Planes de Mejoramiento"
2. Click en tab "Formulación"
3. Crear planes para cada hallazgo
4. Click [Ir a Seguimiento →]
5. Hacer seguimiento mensual
6. Cerrar hallazgos completados
```

#### **PASO 4: Cierre (Módulos de Soporte)**

```
1. Ir a "📁 Módulos de Soporte"
2. Click en tab "Informes de Ley"
3. Generar Informe Ejecutivo Anual
4. Exportar y publicar
```

## ❓ **PREGUNTAS FRECUENTES**

### **P: ¿Dónde está el módulo X que antes existía?**

**R:** Ahora está dentro de un módulo grueso. Mira la tabla:

| Antes | Ahora |
|-------|-------|
| Plan Anual | Planificación > Tab: Plan Anual |
| Universo | Planificación > Tab: Universo |
| Ejecución | Proceso Auditoría > Tab: Ejecución |
| Informes Ley | Soporte > Tab: Informes de Ley |

### **P: ¿Cómo navego entre tabs?**

**R:** Tres formas:
1. Click en el nombre del tab
2. Botones "Siguiente paso"
3. Atajos de teclado (Ctrl + Tab)

### **P: ¿Perdí alguna funcionalidad?**

**R:** No, **todo** está disponible. Solo reorganizado de forma más clara.

### **P: ¿Desde el Dashboard puedo ir a cualquier módulo?**

**R:** Sí, desde las tarjetas del Kanban:
- Click en [📋 Ver Plan] → va a Planificación
- Click en [⚡ Ejecutar] → va a Proceso Auditoría
- Click en [📊 Info] → muestra detalles
