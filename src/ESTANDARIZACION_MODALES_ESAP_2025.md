## 🔧 TEMPLATE DE MIGRACIÓN

### Paso a Paso para Migrar un Modal

#### 1️⃣ **Antes (ModalSIGLPremium o enfoque manual)**

```tsx
// ENFOQUE ANTIGUO CON ModalSIGLPremium
import { ModalSIGLPremium } from '../design-system/ModalSIGLPremium';

<ModalSIGLPremium
  isOpen={isOpen}
  onClose={onClose}
  title="Título"
  subtitle="Subtítulo"
  icon={<IconoComponente />}
  size="xl"
  height="full"
  headerColor="blue"
  badges={[...]}
  footerActions={<>botones</>}
>
  {/* Contenido */}
</ModalSIGLPremium>
```

#### 2️⃣ **Después (ModalHeaderClean - Estándar ESAP 2025)**

```tsx
// NUEVO ESTÁNDAR CON ModalHeaderClean
import { Dialog, DialogContent, DialogTitle, DialogDescription } from '@/components/ui/dialog';
import { ModalHeaderClean } from './ModalHeaderClean';

<Dialog open={isOpen} onOpenChange={onClose}>
  <DialogContent className="max-w-4xl h-[90vh] flex flex-col p-0">
    {/* Títulos ocultos para accesibilidad */}
    <DialogTitle className="sr-only">Título del Modal</DialogTitle>
    <DialogDescription className="sr-only">
      Descripción para lectores de pantalla
    </DialogDescription>

    {/* HEADER - flex-shrink-0 (siempre visible) */}
    <ModalHeaderClean
      icono={<IconoComponente className="w-5 h-5 text-white" />}
      titulo="Título"
      subtitulo="Subtítulo"
      badges={[
        { label: 'Estado', color: 'blue' }
      ]}
      onClose={onClose}
    />

    {/* CONTENIDO - flex-1 overflow-y-auto (solo esto hace scroll) */}
    <div className="flex-1 overflow-y-auto px-6 py-4 bg-gray-50">
      {/* Tu contenido aquí */}
    </div>

    {/* FOOTER - flex-shrink-0 (siempre visible) */}
    <div className="flex-shrink-0 px-6 py-4 bg-white border-t border-gray-200 flex items-center justify-between">
      <div className="text-sm text-gray-600">
        Información adicional
      </div>
      <div className="flex gap-3">
        <Button variant="outline" onClick={onClose}>
          Cancelar
        </Button>
        <Button 
          onClick={handleGuardar}
          style={{ background: '#2962FF', color: '#FFFFFF' }}
        >
          Guardar
        </Button>
      </div>
    </div>
  </DialogContent>
</Dialog>
```

## ✅ CHECKLIST DE VALIDACIÓN POST-MIGRACIÓN

Después de migrar cada modal, validar:

### Funcionalidad
- [ ] Modal abre correctamente

- [ ] Modal cierra con ESC
- [ ] Formularios funcionan (si aplica)
- [ ] Validaciones funcionan (si aplica)
- [ ] Datos se guardan correctamente
- [ ] Toasts de éxito/error aparecen

### Diseño
- [ ] Header usa ModalHeaderClean
- [ ] Fondo blanco limpio (sin gradientes)
- [ ] Footer siempre visible (no se esconde)
- [ ] Solo contenido hace scroll
- [ ] Botones primarios usan azul #2962FF
- [ ] Badges con colores apropiados
- [ ] Iconos claros y visibles

### Responsive
- [ ] Funciona en móvil (< 640px)

- [ ] Funciona en desktop (1024px+)
- [ ] No hay scroll horizontal

- [ ] Botones accesibles en móvil

### Accesibilidad
- [ ] Navegable con Tab/Shift+Tab
- [ ] Cierra con ESC
- [ ] DialogTitle con sr-only presente
- [ ] DialogDescription con sr-only presente
